# 📚 household-back 코드 산책 (Codewalk)

> **FastAPI를 처음 보는 주니어 개발자**가 이 가계부 백엔드를 혼자 읽어나갈 수 있게 만든 도메인별 분석 가이드.
> 코드를 바꾸지 않고, "이 파일이 왜 있고 / 요청 하나가 어떻게 흐르는지" 를 쉽게 풀어낸다.

---

## 누구를 위한 문서인가

- ✅ 이 레포를 **처음 여는 사람** (온보딩)
- ✅ **FastAPI / SQLAlchemy 입문자** — 개념을 코드와 함께 짚어준다
- ✅ 특정 기능이 "어디서 어떻게" 동작하는지 찾는 사람

전제 지식은 거의 없어도 된다. 파이썬 기본 문법 정도만.

## 각 문서의 공통 구성 (7섹션)

어느 도메인 문서를 펴도 같은 틀이라, 한 번 익히면 전부 같은 방식으로 읽힌다.

1. **이 도메인 한마디** — 가계부에서 뭘 담당하나
2. **들어가기 전 (개념 콕)** — 이 문서 읽는 데 필요한 FastAPI/SQLAlchemy 개념만
3. **데이터 모델** — 테이블/컬럼/관계 표 + ERD + "왜 이 컬럼"
4. **공통 메커니즘** — 여러 API가 공유하는 로직(잔액 공식·커서·cascade 등)을 여기 **1번** 깊게. §5 트레이스가 참조한다.
5. **엔드포인트별 풀 트레이스** — API 하나하나를 **요청 → 의존성·검증 → 서비스 → repository 쿼리 → 응답 조립 → commit** 까지 한 줄기로(`file:line`). 이 문서의 메인.
6. **데이터 흐름** — 도메인 전체를 잇는 큰 그림(요청 → 응답 텍스트 다이어그램)
7. **이 문서에서 꼭 기억할 규칙** — 핵심 3~5줄

> **왜 §4와 §5를 나누나:** `_calc_balance` 같은 공통 로직을 API마다 반복하면 분량이 폭증하고 핵심이 흐려진다. 공통은 §4에 한 번만 깊게 두고, §5의 각 API 트레이스는 "그 API 고유의 길"에 집중하며 공통은 `→ §4` 로 참조한다. (00·01 은 도메인이 아니라 개관/인프라라 이 틀과 다르다.)

## 도메인 지도 (의존성 = 누가 누구를 부르나)

```
                       ┌─────────────┐
                       │  household  │  세대(부부 공유 단위) — 모든 데이터의 소유 주체
                       └──────┬──────┘
        ┌──────────────┬──────┴───────┬───────────────┐
   ┌────▼───┐    ┌─────▼────┐   ┌─────▼─────┐    ┌─────▼──────┐
   │ account│    │ category │   │  fixed    │    │ portfolio  │
   │ (통장) │    │(카테고리)│   │(고정지출) │    │  (투자)    │
   └────┬───┘    └─────┬────┘   └───────────┘    └─────┬──────┘
        │  ┌───────────┘                                │
   ┌────▼──▼──────┐                          ┌──────────▼──────────┐
   │ transaction  │  거래(수입/지출/이체)      │ market_price·환율    │ ← 내부 인프라(URL 없음)
   └──────────────┘                          │ snapshot·wealth      │
                                              └─────────────────────┘
   ─────────────── 집계: home / stats / settings / enum / health ───────────────
```

- `account`(37회)·`household`(32회) 가 가장 많이 참조되는 **기반 도메인**.
- `market_price`·`exchange_rate` 는 라우터가 없는 **내부/배치 전용** (스케줄러·portfolio가 호출).

## 참고 (이 문서들의 사실 근거)

문서의 모델·API 서술은 **현재 코드**를 1차 근거로 한다:
- 테이블/컬럼 → `app/domain/*/model.py` + `alembic/versions/`
- 엔드포인트 → `app/domain/*/router.py`
- 로직 → `app/domain/*/service.py`

`ddl/init.sql` 과 `docs/api-list.md` 는 현재 코드와 일부 불일치가 있어 **보조 자료**로만 쓴다.
